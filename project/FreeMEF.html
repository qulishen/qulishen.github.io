Method研究方法

Recurrent State Space Module

The RSSM aligns exposure features adaptively and fuses them sequentially into shared guidance.RSSM 对曝光特征进行自适应对齐，再按序融合为全局引导。

Extremity-Aware Hybrid Attention

EAHA uses reference features to recover information in regions where under- or overexposure makes the base and reference frames look dissimilar.EAHA 从参考帧获取信息，复原因欠曝光或过曝而与参考帧差异较大的区域。

Affine-Injection FFN

AFFN uses statistics from the exposure sequence to adaptively adjust contrast and brightness in the restoration network.AFFN 利用曝光序列的全局统计，自适应调节复原网络中的对比度与亮度。

Quantitative results定量结果

The same model supports 2-, 3-, and 5-frame exposure brackets and reaches 28.418 dB on Kalantari and 26.077 dB on Real-HDRV in the 3-frame evaluation.同一模型支持 2、3、5 帧曝光序列。在三帧评测中，FreeMEF 在 Kalantari 和 Real-HDRV 上的 PSNR 分别为 28.418 dB 和 26.077 dB。
